# FAQ

## Is this a full SNN framework?

No. It is a compact research toolkit for explaining and testing the structural path from ANN to event-driven SNN.

## Why MNIST?

MNIST keeps the first release small and reproducible. The main contribution is the staged transformation logic, not dataset scale.

## Why keep the legacy script?

The original single-file prototype is preserved in `legacy/` so users can trace how the public package evolved from the initial research code.

## Where should benchmark claims go?

Use `docs/benchmark.md` for detailed benchmark context and keep the README table focused on the most important results.
